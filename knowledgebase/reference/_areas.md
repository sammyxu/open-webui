# Reference Areas: Partition, Scopes and Focus

Not a reference document (underscore prefix). This is the Phase 2 partition of MedIT GPT (Open
WebUI v0.11.4, `uoft` branch) into reference areas, with the exact scope each researcher read and
the questions each document must answer. Re-run research for an area from this file after a
release. The application is about 277,000 lines (263 backend Python files, 671 Svelte components),
so the partition runs to 47 areas rather than the method's usual 30 to 40.

Paths are repository-relative. `admin/Settings/<Name>` means `src/lib/components/admin/Settings/<Name>.svelte`
(plus the `<Name>/` folder when it exists); `chat/Settings/<Name>` likewise under
`src/lib/components/chat/Settings/`.
