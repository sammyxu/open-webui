# Deployment, Operations, Logging and Telemetry

## At a Glance

- The repository supports several ways to run MedIT GPT: the Docker image (`Dockerfile`, with
  CUDA, Ollama and slim variants), Docker Compose files, `backend/start.sh`, and the Python package
  started with `open-webui serve`. **Which one production uses is TO BE CONFIRMED.**
- Upgrades run database migrations automatically when the configuration module is imported, in
  every process, unless `ENABLE_DB_MIGRATIONS=False`; a failed migration stops start-up.
- The secret key generated by `backend/start.sh` lives outside the Docker data volume, so a
  recreated container without `WEBUI_SECRET_KEY` signs everyone out.
- Application logs go to standard output only; the optional audit log writes `DATA_DIR/audit.log`
  and contains personal data. `/health` always answers; `/ready` reports start-up and dependencies.
